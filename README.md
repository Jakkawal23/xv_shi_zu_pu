# 許氏族谱 — เว็บผังลำดับวงศ์ตระกูล

เว็บไฟล์เดียว (`index.html`) สำหรับดูลำดับวงศ์ตระกูล 許 เปิดได้ทั้งบนคอมและมือถือ
ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลทั้งหมดฝังอยู่ในไฟล์เดียวกันเป็น JSON
แก้ไฟล์นั้น บันทึก แล้วรีเฟรชหน้าเว็บ ก็เห็นผลทันที

## เปิดเว็บนี้ยังไงบ้าง

- **บนคอม**: ดับเบิลคลิกไฟล์ `index.html` เปิดด้วยเบราว์เซอร์ได้เลย
- **บนมือถือ**: ส่งไฟล์ `index.html` ไปที่มือถือผ่าน LINE / Google Drive / อีเมล
  แล้วเปิดไฟล์นั้นด้วยเบราว์เซอร์ในเครื่อง หรือใช้ลิงก์เว็บที่ publish ไว้ (ขอลิงก์
  ปัจจุบันจากแชทที่คุยกับ Claude ได้ทุกเมื่อ — ถ้าคุณแก้ข้อมูลแล้วอยากให้ลิงก์นั้น
  อัปเดตตาม ให้บอกให้ publish ซ้ำ)

## แก้ไข/เพิ่มข้อมูลคนในตระกูล

เปิด `index.html` ด้วยโปรแกรมแก้ข้อความ (Notepad, VS Code ฯลฯ) แล้วมองหาบล็อกนี้
ใกล้ต้นไฟล์:

```html
<script id="family-data" type="application/json">
{
  "meta": { ... },
  "people": [ ... ]
}
</script>
```

ทุกคนในตระกูลคือหนึ่งบรรทัด (object) ในลิสต์ `people` แก้ค่าตรงนั้นได้เลย แล้ว
บันทึกไฟล์ + รีเฟรชหน้าเว็บ

### ฟิลด์ทั้งหมดของแต่ละคน

| ฟิลด์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `id` | รหัสไม่ซ้ำกันของคนนี้ (ใช้เชื่อมสายตระกูล) | `"p52"` |
| `gen` | ลำดับรุ่นเป็นตัวเลข | `22` |
| `genLabel` | ป้ายรุ่นภาษาจีนต้นฉบับ | `"第二十二代"` |
| `name` | ชื่อภาษาจีน | `"許金菊"` |
| `thaiName` | ชื่อไทย (หรือ `null` ถ้าไม่มี) | `"สมชาย แซ่ฮื้อ"` |
| `order` | ลำดับการเกิด เช่น `長子` `次女` `義女` (หรือ `null`) | `"長子"` |
| `gender` | เพศ `"M"` หรือ `"F"` | `"M"` |
| `parentId` | `id` ของพ่อ/แม่ในสายนี้ (หรือ `null` ถ้าเป็นต้นตระกูล) | `"p21"` |
| `phone` | เบอร์โทรของตัวเอง (หรือ `null`) | `"0899978820"` |
| `email` | อีเมล (หรือ `null`) | `"name@email.com"` |
| `lineId` | ไอดีไลน์ (หรือ `null`) | `"line_id123"` |
| `wechatId` | ไอดีวีแชท (หรือ `null`) | `"wechat_id"` |
| `address` | ที่อยู่ (หรือ `null`) | `"123 หมู่ 4 ต.แม่สาย จ.เชียงราย"` |
| `adopted` | `true` ถ้าเป็นบุตรบุญธรรม (義子/義女) | `false` |
| `photo` | URL หรือ data URI ของรูปภาพ (หรือ `null` = ใช้ตัวอักษรย่อแทน) | `null` |
| `notes` | รายละเอียดเพิ่มเติมแบบข้อความอิสระ (หรือ `null`) | `"ย้ายไปอยู่เชียงใหม่ปี 2540"` |
| `extra` | รายการข้อมูลอื่น ๆ ที่ไม่มีช่องสำเร็จรูป ใส่กี่รายการก็ได้ หรือ `[]` ถ้าไม่มี | ดูตัวอย่างด้านล่าง |
| `spouse` | ข้อมูลคู่สมรส — `null` ถ้าไม่มี หรือ object ที่มีฟิลด์แบบเดียวกับคนได้ | ดูตัวอย่างด้านล่าง |

### ตัวอย่าง: เพิ่มคนใหม่

คัดลอกก้อนนี้ไปแปะต่อท้ายในลิสต์ `people` (อย่าลืมเครื่องหมาย `,` คั่นระหว่างคน)
แล้วแก้ค่าตามจริง:

```json
{
  "id": "p52",
  "gen": 22,
  "genLabel": "第二十二代",
  "name": "許新名",
  "thaiName": "สมชาย แซ่ฮื้อ",
  "order": "次子",
  "gender": "M",
  "parentId": "p26",
  "phone": "0812345678",
  "email": "somchai@email.com",
  "lineId": "somchai_line",
  "wechatId": null,
  "address": "123 หมู่ 4 ต.แม่สาย อ.แม่สาย จ.เชียงราย 57130",
  "adopted": false,
  "photo": null,
  "notes": "ทำงานที่เชียงใหม่",
  "extra": [
    { "label": "เฟซบุ๊ก", "value": "facebook.com/somchai" },
    { "label": "อาชีพ", "value": "ค้าขาย" },
    { "label": "วันเกิด", "value": "12 มี.ค. 2530" }
  ],
  "spouse": {
    "name": "李美玲",
    "thaiName": "มาลี แซ่หลี่",
    "phone": "0898887777",
    "email": null,
    "lineId": null,
    "wechatId": "mali_wechat",
    "address": null,
    "extra": []
  }
}
```

สิ่งที่ต้องระวัง:

- **`id` ห้ามซ้ำ** กับคนอื่นในลิสต์ — ใช้เลขถัดจากคนสุดท้าย (ตอนนี้ไปถึง `p51`)
  ก็ปลอดภัยสุด
- **`parentId`** ต้องตรงกับ `id` ของพ่อหรือแม่ที่มีอยู่แล้วในลิสต์ ไม่งั้นคนนี้จะไม่
  ขึ้นในผังต้นไม้ (ลองค้นหาชื่อดู ถ้าเจอในสายบรรพบุรุษ/ผลค้นหาแต่ไม่โผล่ในต้นไม้
  หลัก แปลว่า `parentId` ผิด)
- ฟิลด์ไหนไม่มีข้อมูล ใส่ `null` ไว้ (ห้ามลบฟิลด์ทิ้งไปเฉย ๆ เพราะ JSON ต้องมี
  comma คั่นระหว่างฟิลด์ให้ครบ — ปลอดภัยสุดคือก็อบปี้ทั้งก้อนตัวอย่างข้างบนไปแก้)
- ถ้าพิมพ์ JSON ผิดรูปแบบ (ลืมปีกกา ลืม comma ฯลฯ) หน้าเว็บจะไม่ขึ้นข้อมูลอะไร
  เลย — เปิด Console ของเบราว์เซอร์ (กด F12) จะเห็นข้อความ error บอกตำแหน่งบรรทัด
  ที่ผิด หรือลองวางเนื้อหาในเว็บตรวจ JSON เช่น jsonlint.com เพื่อหาจุดผิด

### ใส่รูปคนจริงแทนตัวอักษรย่อ

ตอนนี้ทุกคนแสดงเป็นวงกลมตัวอักษรจีนตัวท้ายชื่อแทนรูป (สีต่างกันตามเพศ) ถ้าจะใส่
รูปจริง ใส่ลิงก์รูปในฟิลด์ `photo` เช่น `"photo": "https://example.com/somchai.jpg"`
— (โค้ดส่วนแสดงผลรูปยังไม่ได้ต่อไว้ ถ้าต้องการให้ใช้งานได้จริง แจ้ง Claude ให้
เพิ่มส่วนนี้ให้ได้)

## ค้นหา

ช่องค้นหาด้านบนรองรับ:

- ชื่อจีนตัวเต็ม/ตัวย่อ (พิมพ์ `许金菊` ก็เจอ `許金菊`)
- พินอิน ไม่ต้องใส่วรรณยุกต์ เช่น `yongqing` หรือ `jin ju` (พินอินรองรับเฉพาะ
  ตัวอักษรจีนที่มีอยู่ในข้อมูลเดิม 51 คนแรกเท่านั้น — คนที่เพิ่มใหม่ด้วยชื่อที่ใช้
  ตัวอักษรอื่น จะยังค้นด้วยชื่อจีน/ไทยตรง ๆ ได้ปกติ แต่อาจค้นด้วยพินอินไม่เจอ)
- เบอร์โทร ของทั้งตัวเองและคู่สมรส (พิมพ์บางส่วนของเบอร์ก็เจอ)
- ชื่อไทย ชื่อคู่สมรส อีเมล ไลน์ วีแชท ที่อยู่ หมายเหตุ และข้อมูลใน `extra`

ผลค้นหาจะกางกิ่งของผังต้นไม้ไปหาคนที่เจอให้อัตโนมัติ

## โครงสร้างไฟล์

```
xv_jia_pu/
├── index.html   ← ไฟล์เว็บทั้งหมด (โค้ด + ข้อมูล JSON ฝังอยู่ข้างใน)
└── README.md    ← ไฟล์นี้
```

ไม่มีไฟล์อื่นที่ต้องดูแล ข้อมูลทั้งหมดอยู่ใน `index.html` ไฟล์เดียว

## ข้อควรระวังเรื่องความเป็นส่วนตัว

ไฟล์นี้มีเบอร์โทร ที่อยู่ และข้อมูลติดต่ออื่น ๆ ของคนในครอบครัวจริง **ถ้าจะอัปโหลด
โฟลเดอร์นี้ขึ้น GitHub หรือที่เก็บโค้ดสาธารณะ ให้ตั้งเป็น private repository** หรือ
แยกไฟล์ข้อมูลออกไปก่อน ไม่ควรให้ไฟล์นี้เข้าถึงได้แบบสาธารณะ เพราะมีข้อมูลส่วน
บุคคลของสมาชิกในตระกูลอยู่ครบ
