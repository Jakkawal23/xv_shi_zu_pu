# โฟลเดอร์รูปภาพ

วางไฟล์รูปของแต่ละคนไว้ที่นี่ ตั้งชื่อไฟล์ตาม **`id`** ของคนนั้นใน
`family-data.json` เท่านั้น (ไม่ใช่ชื่อคน) เช่น คนที่มี `"id": "22-11"` ก็เซฟรูป
เป็น `22-11.jpg`

รองรับไฟล์: `.jpg`, `.jpeg`, `.png`, `.webp` (ใช้ชื่อเดียวกัน เปลี่ยนแค่
นามสกุลไฟล์ตามชนิดไฟล์จริง)

หน้าเว็บจะหารูปที่ตรงกับ `id` ของแต่ละคนให้เองอัตโนมัติทุกครั้งที่เปิดหน้า —
ถ้าเจอไฟล์รูปก็จะแสดงแทนวงกลมตัวอักษรย่อทันที ไม่ต้องแก้อะไรใน
`family-data.json` หรือโค้ดเลย ถ้าไม่มีไฟล์รูปสำหรับคนนั้น ก็จะแสดงวงกลม
ตัวอักษรย่อเหมือนเดิม

ตัวอย่าง: ถ้า `family-data.json` มีคนคนหนึ่งเป็น

```json
{ "id": "22-11", "name": "許金寶", ... }
```

ก็แค่นำรูปมาเซฟไว้ที่ `photos/22-11.jpg` (หรือ `.png`/`.jpeg`/`.webp`) เท่านั้น

**หา `id` ของแต่ละคนได้จากไหน?** เปิด `family-data.json` มองหาชื่อคนนั้น
แล้วดูค่า `"id"` ของ record นั้น — รูปแบบคือ `{รุ่นที่}-{ลำดับในรุ่นนั้น}` เช่น
`22-11` คือคนที่ 11 ในบรรดาคนรุ่นที่ 22 ทั้งหมด
